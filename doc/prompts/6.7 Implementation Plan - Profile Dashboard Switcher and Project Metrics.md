# Implementation Plan - Profile Dashboard Switcher and Contextual Project Metrics

Add a window switcher button (`left arrowhead`) to the top-right corner of the Profile card that triggers a smooth, overlapping transition effect to switch to a project performance metrics dashboard window, with contextual metrics for each initiative in `primaryProjects`.

## User Review Required

> [!IMPORTANT]
> - **Window Switcher Interaction**:
>   - On the **Profile Card** (top-right corner): A left arrowhead switcher button (`<i class="fa-solid fa-chevron-left"></i>`) switches the view to the **Ecosystem Metrics Dashboard**.
>   - On the **Metrics Dashboard** (top-right corner): A return switcher button (`<i class="fa-solid fa-chevron-right"></i>`) smoothly switches back to the **Profile Card**.
> - **Overlapping Transition Effect**:
>   - Uses a layered card-stage transition with 3D depth, slide, opacity, and soft overlapping shadows (`cubic-bezier(0.16, 1, 0.3, 1)`), where one window gracefully slides and overlaps over the other without jarring layout jumps.
> - **Contextual Project Metrics**:
>   - Each of the 13 projects in `primaryProjects` will display contextual metrics matching its specific real-world domain (e.g., Resource Archive displays *Curated Materials*, *Bandwidth Served*, *Downloads*; Blood Donation displays *Verified Donors*, *Response Time*, *Lives Impacted*; Academic Scheduler displays *Conflict Rate*, *Batch Syncs*, etc.).

## Proposed Changes

### 1. Markup Structure (`index.html`)

- **Profile Card Switcher Button**:
  - Add a dedicated `#profileSwitchToDashboardBtn` on the top-right of `.profile-card`:
    ```html
    <button type="button" class="window-switcher-btn to-dashboard" id="profileSwitchToDashboardBtn" title="Switch to Initiatives Metrics Dashboard" aria-label="Switch to Initiatives Metrics Dashboard">
        <i class="fa-solid fa-chevron-left"></i>
        <span class="switcher-tooltip">Initiatives Dashboard</span>
    </button>
    ```
- **Profile Stage Container**:
  - Wrap `#profile` contents in a responsive container `.profile-stage` housing:
    1. `.profile-card` (User profile details & edit form)
    2. `.dashboard-card` (`#initiativesDashboardCard`):
       - Header with title *"Ecosystem Metrics Dashboard"*, subtitle *"Telemetry & operational performance across oU1TS initiatives"*, and return switcher button `#dashboardSwitchToProfileBtn` (`<i class="fa-solid fa-chevron-right"></i>`).
       - High-level ecosystem aggregate counter ribbon (Total Initiatives: 13, Average Uptime: 99.8%, Monthly Impact: 45k+ engagements, Health: 100% Operational).
       - Responsive grid container `#projectMetricsGrid` for the 13 project metric cards.

---

### 2. Styling & Overlapping Transitions (`index.css`)

- **Window Switcher Buttons**:
  - Positioned at `top: 18px; right: 18px;` inside `.profile-card` and `.dashboard-card`.
  - Glassmorphic styling with neon glow on hover, smooth arrow rotation, and tooltip feedback.
- **Overlapping Transition Mechanism**:
  - `.profile-stage`: `position: relative; width: 100%; min-height: 600px; perspective: 1200px;`
  - `.profile-card` and `.dashboard-card`:
    - Base layer styles with glassmorphism, responsive max-widths, and smooth cubic-bezier transitions (`transition: transform 0.6s cubic-bezier(0.16, 1, 0.3, 1), opacity 0.5s ease, box-shadow 0.6s ease;`).
    - When switching to Dashboard:
      - `.profile-card.staged-back`: slides slightly to the right, scales down to `0.94`, blurs slightly (`filter: blur(2px)`), drops opacity to `0.3`, and loses pointer events.
      - `.dashboard-card.staged-active`: slides in from the left/right, overlaps on top with `z-index: 20`, full opacity, and deep overlapping elevation shadow (`box-shadow: 0 25px 50px -12px rgba(0, 0, 0, 0.7);`).
- **Dashboard Grid & Metric Cards**:
  - Responsive grid layout (`repeat(auto-fill, minmax(280px, 1fr))`).
  - Sleek squircle mini-header with project icon, name, live status badge (`Operational`, `Live`, `Beta`).
  - Contextual 3-column or 2x2 metric stat pills with metric names, values, and color-coded trend indicators.
  - Health/activity progress bar for each project.
  - Quick action link button to launch the live project in a new tab.
  - Full theme compatibility for both dark mode and light mode.
