# Walkthrough - Custom Responsive Dropdowns with Text Wrapping

Replaced native select elements with an accessible, high-contrast, fully responsive custom dropdown component that stays strictly within the mobile screen bounds and wraps option text across multiple lines.

## Changes Made

### 1. Styling & Viewport Containment (`index.css`)
- **Container Sizing**:
  - Set `.custom-select-container` to `width: 100%; max-width: 100%; box-sizing: border-box; position: relative;`.
- **Menu Clamping**:
  - Styled `.custom-select-menu` with `position: absolute; left: 0; right: 0; width: 100%; max-width: 100%; box-sizing: border-box;`.
  - Constrained maximum height to `240px` with smooth scrollbars, ensuring it never goes outside the screen or creates horizontal scrollbars on mobile viewports.
- **2-Line Text Wrapping**:
  - Configured `.custom-select-option` with `white-space: normal; word-break: break-word; overflow-wrap: break-word; line-height: 1.35; min-height: 42px;`.
  - Options like *"Computer Science & Engineering (CSE)"* and *"Electrical & Electronic Engineering (EEE)"* now wrap into 2 lines naturally.
- **Theme Contrast**:
  - Dark mode: `#161b26` background, `#f8fafc` text, neon blue hover/selection highlights.
  - Light mode: `#ffffff` background, `#0f172a` text, subtle slate-blue hover highlights.

---

### 2. Custom Dropdown Script Engine (`index.js`)
- **Dynamic Attachment (`initCustomDropdowns`)**:
  - Automatically wraps all `<select>` inputs in `.input-wrapper` (`#registerDept`, `#editDept`, `#editBlood`).
  - Hides native `<select>` with `.visually-hidden-select` while keeping it accessible and connected to form validation.
  - Built custom trigger buttons with live labels and rotating chevron arrows.
- **Form Synchronization**:
  - Clicking a custom option updates the hidden `<select>.value` and dispatches standard `change` events.
  - When `populateProfileUI()` programmatically updates values, `select._updateCustomDropdown()` synchronizes the visible trigger label immediately.
- **Interactivity & Keyboard Navigation**:
  - Supports click toggling, auto-closing other open menus, Escape key dismissal, and outside-click dismissal.
