# Walkthrough - Profile Dashboard Switcher and Contextual Project Metrics

Added a window switcher button (left arrowhead) on the top-right corner of the Profile card that triggers an overlapping transition animation to reveal an Ecosystem Performance Metrics Dashboard displaying contextual metrics for all 13 primary projects.

## Changes Made

### 1. Window Switcher & Dashboard Markup ([`index.html`](index.html))
- **Profile Stage Wrapper (`#profileStageWrapper`)**:
  - Encapsulates `.profile-card` (`#profileCardWindow`) and `.dashboard-card` (`#initiativesDashboardCard`) within a single stage container that supports 3D perspective and overlapping transitions.
- **Top-Right Switcher Buttons**:
  - On `#profileCardWindow`: Added `#profileSwitchToDashboardBtn` with `<i class="fa-solid fa-chevron-left"></i>` (left arrowhead) and hover tooltip *"Initiatives Dashboard"*.
  - On `#initiativesDashboardCard`: Added `#dashboardSwitchToProfileBtn` with `<i class="fa-solid fa-chevron-right"></i>` and hover tooltip *"Back to Profile"*.
- **Dashboard Structure**:
  - Header with icon badge, title *"Initiatives Performance Metrics"*, and subtitle.
  - Ecosystem Aggregate Stats ribbon:
    - **13** Active Initiatives
    - **99.8%** System Health
    - **45k+** Monthly Engagements
    - **100%** Open Ecosystem
  - Responsive project grid container (`#projectMetricsGrid`).

---

### 2. Centered Seamless Overlay Transitions & Glassmorphic Styling ([`index.css`](index.css))
- **Centered Grid Stack (`.profile-stage-wrapper`)**:
  - Configured with `display: grid; grid-template-areas: "card"; justify-items: center; align-items: start;` so both the profile card and dashboard card remain aligned on the exact same center axis without horizontal jumps.
- **Centered Place Down & Pick Up Animation**:
  - **Placing Down (`anim-place-down` on Dashboard, `anim-covered-under` on Profile)**:
    - The Dashboard card arrives directly from near the center (starts slightly elevated with `scale(1.05) translateY(-20px)`, blur, and soft shadow), dropping smoothly down into place (`scale(1) translateY(0)`) and completely covering the centered Profile card beneath it.
    - The Profile card stays centered, gently scaling to `0.97` and settling under without sliding sideways.
  - **Picking Up (`anim-pick-up` on Dashboard, `anim-reveal-under` on Profile)**:
    - Reversing the view picks up the Dashboard card off the stack, elevating it (`scale(1.06) translateY(-24px)`) and fading it out.
    - The Profile card immediately reveals directly underneath in its centered position.
- **Project Metric Cards**:
  - Modern squircle header with project icon, name, category, and live status badge (`Operational`, `Beta Testing`, `In Development`) featuring a glowing pulsating indicator.
  - Contextual 1-line summary and dynamic progress track for system health.
  - 2x2 grid of contextual KPIs with labels, values, and colored trend indicators.
  - Direct launch button linking to live URLs (or disabled "In Development" button for WIP projects).
  - Full support for both dark theme and light theme.
