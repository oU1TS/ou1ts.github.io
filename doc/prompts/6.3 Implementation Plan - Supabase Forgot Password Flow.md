# Implementation Plan - Supabase Password Recovery Flow

Add a "Forgot Password?" trigger to the login interface and implement the end-to-end Supabase password recovery workflow.

## User Review Required

> [!IMPORTANT]
> **Does this work with Supabase?**
> **Yes, 100% natively.** Supabase Auth includes built-in email password recovery via `supabase.auth.resetPasswordForEmail(email, { redirectTo })`.
> When the user clicks the recovery link in their email, Supabase redirects them back to our app with a secure recovery token, firing the `PASSWORD_RECOVERY` auth event so they can choose a new password.

## Proposed Changes

### 1. Authentication UI (`index.html`)
- **Add "Forgot Password?" Link**:
  - In `#loginForm`, place a `"Forgot Password?"` text button adjacent to the Password field label.
- **Add Password Reset Modal / Card View**:
  - Add a dedicated `#resetPasswordModal` or view containing:
    1. **Request Reset State**: Email input + "Send Reset Link" button + "Back to Sign In" option.
    2. **Set New Password State**: New Password + Confirm New Password inputs + "Update Password" button (shown automatically when the user arrives via a recovery link).

### 2. Styling (`index.css`)
- Style `.forgot-password-link` with subtle glassmorphic hover effect and `var(--accent-blue)` accent.
- Style the reset password dialog and new password input fields with matching dark/light mode standards.

### 3. Supabase Auth Integration (`index.js`)
- **Request Recovery Email**:
  ```javascript
  await supabaseClient.auth.resetPasswordForEmail(email, {
      redirectTo: window.location.origin + window.location.pathname + '#reset-password'
  });
  ```
- **Listen for `PASSWORD_RECOVERY` Event**:
  - In `supabaseClient.auth.onAuthStateChange((event, session) => ...)`:
    - Catch `event === 'PASSWORD_RECOVERY'`.
    - Automatically open the "Set New Password" form.
- **Update Password Handler**:
  ```javascript
  await supabaseClient.auth.updateUser({ password: newPassword });
  ```
  - Validates password length (min 6 characters) and matches confirmation.
  - Displays success message and logs the user into their profile.
